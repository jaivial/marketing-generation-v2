# Security Policy

## Reporting

Report vulnerabilities by email to **security@menustudioai.com**
(fallback: **marketing@menustudioai.com**).

Do **not** file public GitHub issues for security reports.

Include a description, reproduction steps and any impact assessment.

## Acknowledgement

We acknowledge every report within **48 hours** of receipt.

## Disclosure policy

We follow coordinated disclosure with a **90-day** window before public
disclosure, so a fix can be shipped first.

## Scope

- The FastAPI application (`app/`)
- The SQLite store used for persistence
- The Stripe integration (credit purchases and webhooks)
